# Fichas de personajes

Una ficha por personaje que habla (`nombre.md`) y una por personalidad de demonio para las negociaciones (`personalidad-nombre.md`). Las escribe el perfilador a partir del inglés del juego y las aprueba el usuario. Sin spoilers: solo cómo habla cada uno, nunca qué le pasa en la historia.

## Plantilla

```markdown
# Nombre

- **Género:** (como lo marca el juego; si no se sabe, «pendiente»)
- **Trato:** tú o usted, y con quién (STYLE E-30)
- **Registro:** casual, formal, de época...
- **Muletillas y tics:** (según el inglés)
- **Groserías:** cuáles y con qué intensidad
- **Ejemplos:** dos o tres claves de líneas que lo muestran
- **Fuente:** las claves leídas para armar la ficha
```

## Personalidades de demonio

En las negociaciones, una misma línea la dicen demonios de distinto género (STYLE E-41). La ficha de una personalidad describe su voz (registro, muletillas, cómo trata al jugador) y nunca marca el género de quien habla.
