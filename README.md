# smt4-apocalypse-esp

Traducción fan al español de *Shin Megami Tensei IV: Apocalypse* (Nintendo 3DS).

**Estado:** en preparación; todavía no hay parche.

- [PLAN.md](PLAN.md): decisiones, pendientes y fases.
- [TEAM.md](TEAM.md): cómo se reparten la traducción y la revisión.
- [tools/](tools): extraer los archivos del juego (`ctr.py`) y leer y escribir sus mensajes (`mbm.py`).

El repositorio guarda solo nuestra traducción y nuestras herramientas, nunca texto del juego ni la ROM.
